Pulse apps 27 Oct 2026 · new Android key (reinstall needed)

EduPulse 1.6.0 · PulseHMIS 2.4.0 · PulseLMIS 2.3.1 · PulseStock 1.1.0 · PulseProperty Pro 1.1.0 · PulseRemit Pro 1.4.0

⚠️ Android: new signing key, so you must reinstall

This release is signed with a new Pulse Generation UG key. Android will refuse to install it over the old app. To update:

  1. Open the app and make a backup (Settings → Backup).
  2. Make sure the backup is not only inside the app: share or save the backup file to Google Drive, WhatsApp, e-mail or a computer, or use the app's cloud backup where it has one. Uninstalling deletes everything stored inside the app.
  3. Uninstall the old app.
  4. Install the new APK below.
  5. Open it and restore your backup.

If you use several phones on one network, update the head-office or host computer first.

Windows: close the app, download the new Setup.exe and run it. Your data stays. Windows may show "Windows protected your PC": click More info → Run anyway. The -Windows.zip files are portable copies for advanced users, and they need the Microsoft Visual C++ runtime already installed.

What's new

Every app:

  • Global currency list. All apps now use the current ISO 4217 list from September 2026. Currency pickers are searchable by code, number, name or country. Withdrawn currencies stay readable in old records but cannot be chosen for new ones.
  • Messages and notices from Pulse Generation UG (already in PulseLMIS) now come to EduPulse, PulseHMIS, PulseStock, PulseProperty Pro and PulseRemit Pro, with Unread and From Pulse filters.

PulseHMIS 2.4.0:

  • 13 interface languages.
  • Safer pharmacy and injection room:
    • checks for allergies (including drug classes), duplicate therapy, missing dose, route or frequency, and high-alert medicines;
    • a critical alert needs a written reason to continue, and every override is audited.
  • Controlled medicines: a witness is required, and the register shows a running balance.
  • Quarantine, release and recall of batches, with a trace of the patients who received a recalled batch. Expired or recalled stock can never be released. Medicines returned by patients go to quarantine, never straight back to the shelf.
  • A full stock ledger with reconciliation. A double tap or retry can no longer dispense the same prescription twice.
  • Batch and expiry are recorded for every dose given, and expired products are refused.
  • Critical lab results must be read back and acknowledged.

PulseRemit Pro 1.4.0: automatic daily backup on the host computer (the newest 30 are kept).

PulseLMIS 2.3.1: updated currencies (Bulgaria now uses EUR; Curaçao and Sint Maarten now use XCG) and searchable long lists.

The Mac downloads have not changed in this release.
