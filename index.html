Core Architecture

A Queue For Every Department

A Receptionist only ever registers a patient and sends them on. Vitals, diagnosis, and prescriptions are the Doctor's Office's job alone — every screen shows exactly what that role needs, and nothing else.

  • Structured Vitals:Temperature, blood pressure, pulse, respiratory rate, SpO2, and more — individually recorded, with BMI calculated automatically.
  • Multi-Diagnosis Selection:Pick from a built-in list of common conditions, or add one that isn't listed — a patient can carry more than one at a time.
  • Real Prescription Detail:Route, strength, frequency, and duration for every medicine — including sequential treatments like an IV course followed by an oral one.

Built For Real Clinics

No Internet? No Problem.

One computer runs as the Host; every other computer or phone in the building connects to it as a Client over the same Wi-Fi — entirely local, entirely private.

  • Host + Client Architecture:Any Windows PC can be the Host; any other Windows PC or Android device joins as a Client.
  • Nothing Leaves The Building:Patient data stays on the clinic's own network — no cloud account required to keep the system running.
  • One Role, One View:A Receptionist, Doctor, Lab Technician, Cashier, Pharmacist, and Nurse each sign in to see only their own department.

FAQ

Frequently Asked Questions

Got questions? We've got answers

How do I download and install FixIt Enterprise?

Click the Download for Android button in the FixIt Enterprise section. Once downloaded, open the APK file and allow installation from unknown sources in your device settings.

Does PulseHMIS need an internet connection to run?

No. One computer runs as the Host and every other computer or phone in the clinic connects to it over the local Wi-Fi network — no internet connection or cloud account is required for day-to-day use.

Is BTWM free, and do I need to belong to the ministry to use it?

Yes, BTWM is free to download. It's built for the Back To The Word Ministries community, but anyone is welcome to create an account, read the Bible, and follow along with devotionals and services.

Can PulseHMIS run on both Windows and Android at the same clinic?

Yes — that's exactly how it's meant to run. A front-desk PC typically runs the Windows version as the Host, while phones or tablets in other departments run the Android version as Clients connected to it.

How does the 150+ ISO currency wheel work?

The ISO wheel is a native CupertinoPicker that handles massive international currency datasets without standard UI rendering overhead. Simply scroll to select your currency — it's fast and seamless.

Can I print reports directly from either app?

Yes. FixIt Enterprise features native AirPrint integration, and PulseHMIS prints reports, receipts, lab results, and prescriptions straight to any printer already set up on the computer.

Is my data secure?

FixIt Enterprise uses enterprise-grade encryption with Supabase Row-Level Security and Firebase security rules. PulseHMIS keeps patient data local to the clinic's own network by design, and BTWM protects member data with Row-Level Security on every table — none of it is ever sent anywhere outside what each app is meant to do.

Privacy Policy

Effective Date: May 3, 2026

This policy covers all three applications published by Pulse Generation UG: FixIt Enterprise, PulseHMIS, and BTWM. We prioritize your data security in all three.

FixIt Enterprise — Data Handling

We do not collect personal identification information unless voluntarily provided via support channels. All data is encrypted and stored securely using industry-standard protocols including Supabase Row-Level Security and Firebase security rules.

PulseHMIS — Data Handling

PulseHMIS is built to keep patient and facility data on the clinic's own computers and local network by design. It does not require an internet connection or cloud account to operate, and does not transmit patient data outside the facility's own network unless the facility itself chooses to back it up externally.

BTWM — Data Handling

BTWM stores your profile, posts, prayer requests, and messages securely in Supabase, protected by Row-Level Security so members can only see and edit what they're meant to. Voice Room calls connect participants directly to one another (peer-to-peer); the audio itself does not pass through or get stored on our servers.

Permissions Required

  • Internet Access: Used by FixIt Enterprise to sync across multi-cloud infrastructure; used by PulseHMIS only for local network sync between clinic computers; used by BTWM for community, chat, and Voice Room features.
  • Phone Call Access: To facilitate direct contact with support hotlines.
  • Microphone Access: Used by BTWM only when you choose to send a voice message or join a Voice Room.
  • Storage Access: To save generated PDF reports, export data, and upload photos.
  • Print Service: For native printing of reports, receipts, and clinical documents.

Data Retention

FixIt Enterprise and BTWM data are retained only as long as your account is active. PulseHMIS data is retained on the facility's own computers for as long as the facility chooses. You may request complete deletion at any time through the relevant app's settings (BTWM includes an in-app "Delete Account Permanently" option) or by contacting our support team.
