每个科室

机构真正需要的一切。
没有任何拼凑。

仪表板

一目了然的概览，以及找人的最快方式。

  • 按姓名、患者编号、就诊编号或电话即时搜索
  • 进行中的就诊、今日登记、待化验和待付款
  • 在每台局域网同步的电脑上实时显示

前台

每次就诊的起点。

  • 新患者或复诊患者查询
  • 现金、保险（含保险公司）或赊账，一次设定
  • 过敏信息被记录并沿用

诊室

临床决策，计算由系统完成。

  • 生命体征，自动计算 BMI 和疼痛评分
  • 快速选择诊断，过敏横幅始终可见
  • 处方自动计算数量，并支持“然后继续使用…”的疗程衔接

化验室

按每项检验所需的格式呈现结果。

  • 文本、数值、段落或完整参数表
  • 按年龄和性别区分的参考范围，并标记异常
  • 在化验台即可加项；化验窗口收费全程跟踪

收费处

完整、透明的账单。

  • 问诊、化验和药房费用一张明细
  • 部分付款、折扣和“账上余额”
  • 多收前先确认；收费从不阻碍治疗

药房

精准发药，标签清晰。

  • 按正确顺序衔接的处方
  • 按药品切换“已发药”
  • 热敏打印机处方标签

注射室

每一剂、每一班，都有据可查。

  • 计划、已给、剩余剂量及剩余天数
  • 每剂标记为早、午、晚或夜
  • 每次给药的“10 项正确”安全核对清单

报表与分析

随时掌握机构运营状况。

  • 收入、收费、化验、医生、药房和治疗报表
  • 按检验项目的阳性/阴性统计
  • CSV 导出到“文档”文件夹

设置与目录

按贵机构的需要定制 PulseHMIS。

  • 单徽标或双徽标抬头
  • 药品目录、化验项目目录和服务项目
  • 全球货币、文档字号、JSON 备份

局域网同步

每个工作站都同步，就在您的楼内。

一台电脑作为 主机。其他所有电脑、平板或手机都是 客户端 ，运行在您自己的 Wi-Fi 或有线网络上。全程不涉及互联网。

  • 先保存在本地。 每项更改立即写入设备，然后在后台推送到主机，屏幕不会卡顿。
  • 用修订号，而不是时钟。 只有主机分配修订号，因此不会因为两台电脑时间不一致而丢失较新的修改。
  • 对网络负担很小。 客户端每隔几秒询问一次“有更新吗？”，只有内容变化时才下载压缩数据。
  • 稳健可靠。 主机无法连接时，客户端会继续使用最后一份副本工作。单条错误记录不会影响所有人的同步。
  • 几分钟即可添加一台电脑。 安装后指向主机，完整历史会在一个同步周期内到达。

PulseHMIS 常见问题

哪台电脑应作为主机？

通常是前台或管理员的 Windows 电脑，因为它一天中大部分时间都开着。任何平台都可以作为主机，单台电脑的诊所可直接使用独立模式。

主机电脑坏了怎么办？

将最新备份（位于“文档 › Backups”中的可读 JSON 文件，易于复制到 U 盘）恢复到新电脑并设为主机。期间客户端会继续使用最后一份副本工作。

如何支付订阅费用？

MTN Mobile Money、Airtel Money、Visa/Mastercard 或银行转账。您也可以直接付款，并通过以下方式发送凭证： WhatsApp 并附上设备 ID；我们会回复一个可完全离线使用的激活密钥。

可以更正以往的就诊记录吗？

可以。管理员和医生可从患者档案中心打开任何就诊，在任意阶段编辑信息、问诊、化验结果或账单。每项更改都会保存在审计记录中。

保险患者能看到我们的内部价格吗？

不会。对于保险患者，打印文件只显示“付款方式：保险（公司）”，绝不显示内部价格明细。
