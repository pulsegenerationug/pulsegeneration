问题解答。

没找到需要的内容？ 给我们留言 我们会回复您。

安装下载需要账户吗？

不需要。所有下载均免费且无需账户。只需在以下位置选择应用和平台： 下载.

安装Android 提示应用来自未知来源，这正常吗？

正常。凡是在 Play 商店以外安装的应用，Android 都会这样提示。请允许 安装未知应用 （针对您的浏览器或文件管理器），然后点按“安装”。我们的 APK 直接来自官方 GitHub 发布页。

安装Windows 显示 SmartScreen 警告，该怎么办？

SmartScreen 可能会对较新发布者的安装程序发出警告。请选择 更多信息，然后 仍要运行，然后按照安装步骤操作。应用随后会出现在“开始”菜单和桌面上。

安装可以在 iPhone 或 Mac 上使用这些应用吗？

Mac：可以，除 PulseLMIS（支持 Android 和 Windows）外，每款应用都有 Mac 版。iPhone 和 iPad：暂不支持，相关版本正在接受 App Store 审核；在此之前，请使用 Android 手机或平板、Windows 电脑或 Mac。

PulseHMISPulseHMIS 需要联网吗？

不需要。所有临床流程（登记、问诊、化验、收费、药房和注射室）都通过贵机构自己的局域网完全离线运行。只有许可证检查、分支间消息和更新通知会使用互联网，且绝不会阻碍患者诊疗。

PulseHMIS各科室如何保持同步？

一台电脑作为 主机；其他所有电脑或平板作为 客户端 运行在同一 Wi-Fi 或有线网络上。更改先在本地保存，再在后台同步到主机，使用修订号而非时钟，因此即使设备时间不一致也不会丢失任何内容。 了解工作原理.

PulseHMISPulseHMIS 多少钱？

安装免费，含 30 天完整试用。之后每个机构每月 50,000 UGX（6 个月 200,000、一年 400,000，或终身许可 1,500,000），网络内所有电脑均包含在内。订阅到期时，只有管理功能会暂停，临床诊疗永不中断。 查看价格.

PulseHMIS患者信息受保护吗？

是的。每个岗位（前台、医生、护士、化验、收费、药房、管理员）只能看到所需内容。密码以加盐哈希形式存储，每项操作都记录在就诊审计记录中，任何临床数据都不会离开您的网络。

EduPulse哪些机构可以使用 EduPulse？

中小学、学院、大学以及职业和培训机构，公立私立皆可。学期制、评分标准和货币均可配置，不会被固定为某一种体系。

EduPulseEduPulse 能打印带有我校校徽的成绩单吗？

可以。只需设置一次抬头：校徽放左侧、右侧或两侧，以及校训、地址和联系方式。每份成绩单、收据、工资条和报表都会自动使用，并可按需加上签名和校章。

EduPulseEduPulse 能离线使用吗？

可以。学生登记、考勤、成绩、学费、收据、成绩单、工资、备份和打印都可离线使用，并安全地存储在您设备上的本地数据库中。

Ludo可以离线玩 Lwasa Ludo 吗？

可以。与电脑对战，或最多四人在同一设备上轮流游玩。完全离线：无需账户、无需联网，也不收集任何数据。

LudoLwasa Ludo 会收集什么？

什么都不收集。没有账户、没有广告、没有统计分析，应用也没有联网权限。您的进度、金币和奖杯都保存在设备上。阅读完整的 Lwasa Ludo 隐私政策.
